# Roadmap

Planned and possible future work, roughly in priority order. Suggestions are welcome in the issues.

## Before 1.0

- [ ] Validate against real accounts: number matching (`ext_numbers`) for inbound and outbound calls,
      public vs private recording URLs (see [_docs/ringover_api_notes.md](_docs/ringover_api_notes.md)).
- [ ] Native-speaker review of the translations.
- [ ] Code signing for Windows and notarization for macOS.

## Later

- [ ] Several contacts in one run (list or CSV import).
- [ ] Optional storage of the API key in the operating system keychain (opt-in, off by default).
- [ ] Dark theme.
- [ ] Command-line interface reusing the `core` and `ringover-client` modules.
- [ ] Filter by call direction or minimum duration.
